# Painted egg art, one per slime

Every species already has its own egg in the game (the element egg, tinted with the slime's colours and marked with a pattern). To replace one with hand-painted art, save a transparent PNG as `public/eggs/<id>.png` using the id in the table. It is picked up automatically, no code change. Species without a file keep the generated egg.

## Prompt template (paste into your image tool, one egg at a time)

> A single painted fantasy creature egg, front view, centred, soft rim light, thick dark outline, glossy hand-painted game-art style matching the RareSlime Forge eggs. The egg belongs to a **{NAME} Slime** ({ELEMENTS}, {RARITY}). Decorate the shell with markings and colours that suggest that slime: {IDEA}. Rarer slimes get more elaborate, glowing shells. Plain transparent background, no text, no shadow on the ground, square canvas 512x512, egg fills 85% of the height.

Rules: the egg must look like an egg at 80px wide, so keep markings bold and few. Keep the same outline weight and lighting on every egg so they sit together in the hatchery. Check each portal's rule on AI-generated art before using these in a submission.
